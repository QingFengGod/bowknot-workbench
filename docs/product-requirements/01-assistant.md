## 1. 模块定位

助手模块承载用户与**主 Agent（助理）**的日常单聊，是产品的情感入口。

主 Agent 与其他 Agent 共用同一套能力模型（人设、长期记忆、插件权限），差异在于：

- 系统内置、唯一、不可删除
- 拥有虚拟形象，以全局悬浮卡片呈现，可说话、表达情绪、执行动作
- 支持全局语音输入，可在任意页面唤起对话
- 在群聊中额外承担任务派发与汇总职责（群聊见 [03-group-chat.md](./03-group-chat.md)）

本模块负责**主 Agent 的单聊体验**，并定义全局悬浮形象卡片与全局语音的行为；不负责 Agent 创建、群聊、插件安装与记忆管理页面。

## 2. 目标与非目标

### 2.1 目标

- 用户打开助手即可开始对话，无额外操作成本
- 对话过程有“被陪伴”的感知：形象、语音、情绪与动作自然联动
- 形象以全局透明悬浮卡片存在，不占据页面空间，可随时隐藏
- 任意页面可通过全局快捷键发起语音对话，不打断当前工作
- 单聊上下文连续，会话可切换，长期记忆跨会话共享
- 语音输入与播报可独立开关，失败时不影响文字对话

### 2.2 非目标

- 不在本模块创建或编辑 Agent 人设
- 不在本模块管理插件与工具授权
- 不在本模块提供完整的记忆管理页面
- 不在本模块实现群聊与多 Agent 协作
- 不实现操作系统级桌面悬浮窗，全局仅指工作台内所有页面
- 首期不做视频通话、多人语音、实时摄像头

## 3. 用户与场景

| 场景 | 用户诉求 | 页面表现 |
| --- | --- | --- |
| 日常问候 | 快速开始对话 | 打开即进入默认会话，形象以欢迎状态出现 |
| 情绪陪伴 | 被倾听、被回应 | 回复带情绪，形象同步表情与语气 |
| 专注文字 | 不被形象干扰 | 隐藏形象卡片，聊天区占满 |
| 语音交流 | 不方便打字 | 按住说话，转写后确认发送；回复自动播报 |
| 会话切换 | 工作与生活分开聊 | 新建会话，记忆仍然连续 |
| 回看对话 | 找回之前说过的内容 | 消息列表可滚动回看，可复制、重答 |

## 4. 页面结构

### 4.1 布局原则

- **聊天优先**：助手页以对话为主体，形象不占据页面布局
- **形象全局化**：主 Agent 形象由 layout 全局层渲染为悬浮卡片，跨页面常驻
- **开关在顶部栏**：显示 / 隐藏由 layout 顶部按钮控制，助手页不再提供形象开关
- **会话面板右侧常驻**：默认展开，可整体收起；新建、删除、重命名、切换都在面板内完成
- **不打断对话**：切换页面、显隐卡片、拖拽卡片、收起面板都不影响消息与输入草稿
- **小屏适配**：悬浮卡片与小屏下的会话面板都不得遮挡输入区与发送按钮

### 4.2 页面布局

```text
┌────────────────────────────────────────────────────────────┐
│ layout 顶部栏：主 Agent 开关 · 主题 · 用户头像               │
├──────────────────────────────────────────────┬─────────────┤
│ 主 Agent 名称 · 状态        [会话] [设置]     │ 会话         │
├──────────────────────────────────────────────┤ [＋ 新会话]  │
│                                              │ 日常         │
│              消息列表                         │ 工作         │
│                                              │ 学习         │
│                                              │              │
├──────────────────────────────────────────────┤ [收起]       │
│ [文本框...] [麦克风] [播报] [发送]            │              │
└──────────────────────────────────────────────┴─────────────┘
```

悬浮形象卡片独立浮在页面之上，不属于助手页 DOM 布局；其位置与显隐状态由全局层维护。会话面板位于助手页右侧，收起后仅保留顶部栏“会话”按钮。

### 4.3 区域说明

| 区域 | 内容 | 说明 |
| --- | --- | --- |
| layout 顶部栏 | 主 Agent 显示 / 隐藏按钮、主题切换、用户头像 | 全局唯一入口，见 [00-overview.md](./00-overview.md) |
| 页面顶部栏 | 名称、在线状态、会话面板开关、设置 | 状态需能表达思考中、播报中 |
| 消息列表 | 用户消息、Agent 消息、系统提示、任务结果 | 支持流式、Markdown、代码块 |
| 输入区 | 文本框、麦克风、播报开关、发送 | 支持 Enter 发送、Shift+Enter 换行 |
| 会话面板 | 新建、列表、重命名、删除、收起 | 位于右侧，默认展开，详见 5.3 |
| 全局悬浮卡片 | 形象、状态、互动工具条 | 详见 5.1 |

## 5. 功能需求

### 5.1 全局悬浮形象卡片

#### 5.1.1 归属与显隐

- 卡片由 layout 全局层渲染，在工作台所有页面可见，不属于助手页
- layout 顶部栏提供唯一开关按钮，图标与提示随状态变化（显示形象 / 隐藏形象）
- 默认显示；用户隐藏后跨页面保持隐藏，重启后沿用上次状态
- 卡片显隐不影响语音输入与播报；隐藏时仍可通过全局快捷键对话

#### 5.1.2 视觉形态

- 纯透明：无底板、无边框、无阴影，只呈现形象本身
- 只保留形象与一个轻量状态标识；不显示消息气泡、转写文字或输入框
- 鼠标悬停时在形象下方显示极简工具条：拖拽手柄、隐藏、快捷动作
- 工具条在鼠标移出 2 秒后淡出，避免长期遮挡
- 浅色与深色背景下都需可读；必要时由渲染层自带描边或投影，不使用卡片底板

#### 5.1.3 拖拽与层级

- 卡片可拖拽到视口内任意位置，拖拽时显示半透明轮廓
- 拖拽范围限制在可视区域内，不能完全移出屏幕；靠近边缘时自动吸附
- 位置按浏览器窗口尺寸分别记忆；窗口缩放后若越界，自动回到右下角默认位置
- 层级高于页面内容，低于弹窗、抽屉与全局消息提示
- 卡片不得遮挡 layout 顶部栏与左侧导航；拖拽经过时保持可点击
- 提供“复位位置”操作，长按或右键工具条可触发

#### 5.1.4 语义状态

| 状态 | 触发时机 | 结束条件 |
| --- | --- | --- |
| 待机 | 无输入、无生成、无播报 | 收到新事件 |
| 聆听 | 用户开始语音输入 | 录音结束或取消 |
| 思考 | 请求已发送、首个 token 未到 | 开始输出或失败 |
| 说话 | 回复播报中 | 播报结束或被打断 |
| 情绪 | 回复内容或用户互动触发 | 持续 3–5 秒后回到待机 |
| 动作 | 回复内容或用户指令触发 | 动作播放完毕 |

- 情绪与动作是叠加层，底层始终有待机 / 聆听 / 思考 / 说话状态
- 同一时间只播放一个动作；新动作会中断旧动作
- 用户手动互动优先于 AI 自动触发的情绪与动作
- 播报期间口型同步由渲染层负责，UI 只消费“说话中”状态

#### 5.1.5 手动互动

| 交互 | 反馈 | 说明 |
| --- | --- | --- |
| 单击头部 | 摸头反应（害羞 / 开心） | 冷却 2 秒，避免连续触发 |
| 单击面部 | 戳脸反应（惊讶 / 生气） | 冷却 2 秒 |
| 工具条：挥手 | 挥手动作 | 播放一次 |
| 工具条：点头 | 点头动作 | 播放一次 |
| 工具条：跳舞 | 跳舞动作 | 完整播放，可被新动作打断 |
| 工具条：生气 | 生气表情 + 动作 | 播放一次 |

- 拖拽与点击需要区分：移动超过 4px 视为拖拽，不触发互动
- 用户开启“减少动态效果”后，动作降级为静态表情或短过渡

#### 5.1.6 加载与降级

- 形象加载中显示占位轮廓与状态文字，不出现空白区域
- 渲染失败时显示静态形象 + 状态文字，工具条提供“重新加载”
- 页面不可见或卡片隐藏时暂停渲染循环，降低资源占用
- 视频渲染方案下，加载失败同样回退到静态图

### 5.2 对话

#### 5.2.1 基础能力

- 发送文字消息后立即上屏，显示“发送中/已发送/失败”状态
- Agent 回复以流式方式逐字上屏
- 支持 Markdown 渲染：标题、列表、表格、代码块、链接
- 代码块支持复制；链接默认在外部打开，需二次确认
- 消息支持复制、重新生成、删除
- 重新生成只替换当前回复，不改动用户消息

#### 5.2.2 生成过程

- 生成中显示“停止生成”按钮，点击后保留已生成内容
- 生成失败显示错误原因与“重试”，不清空用户输入
- 用户向上滚动查看历史时，不强制回到底部；出现“回到底部”按钮
- 切换会话或隐藏形象卡片时，正在生成的回复继续完成，不中断请求

#### 5.2.3 消息操作

| 操作 | 入口 | 约束 |
| --- | --- | --- |
| 复制 | 消息悬浮操作栏 | 复制纯文本，保留 Markdown |
| 重新生成 | 最后一条 Agent 消息 | 仅最后一条可重答 |
| 删除 | 消息悬浮操作栏 | 二次确认；删除后不可恢复 |
| 播报 | Agent 消息悬浮操作栏 | 单条播报，打断当前播报 |

首期不支持附件、图片与文件上传，作为开放问题保留。

### 5.3 会话管理

#### 5.3.1 会话模型

- 主 Agent 默认存在一个“日常”会话，打开助手即进入最近使用的会话
- 用户可新建多个会话，每个会话独立保存消息历史与短期上下文
- 所有会话共享主 Agent 的长期记忆，不共享短期上下文
- 会话按最近更新时间倒序排列

#### 5.3.2 会话面板

- 位于助手页右侧，默认展开，宽度建议 260–320px
- 面板可整体收起，收起后顶部栏保留“会话”按钮用于重新展开
- 面板结构：标题、新建按钮、会话列表、收起按钮
- 列表项展示：标题、最后一条消息摘要、相对时间、当前会话高亮
- 鼠标悬停时显示重命名与删除操作
- 面板展开状态按用户记忆，跨页面与重启保持
- 窄屏（<1024px）下默认收起，展开时以覆盖式抽屉呈现

#### 5.3.3 会话操作

| 操作 | 规则 |
| --- | --- |
| 新建 | 点击“新会话”立即创建并进入，默认标题“新会话 + 日期”；首条用户消息后自动生成标题，可手动修改 |
| 切换 | 点击列表项切换；每个会话保留自己的输入草稿，切回时恢复 |
| 重命名 | 列表项内联编辑；空标题不允许保存；回车保存，Esc 取消 |
| 删除 | 二次确认；至少保留一个会话；删除当前会话后自动切到最近一个 |
| 收起面板 | 点击收起按钮或顶部栏按钮；不改变当前会话与草稿 |

#### 5.3.4 上下文策略

- 单个会话内保留最近上下文；超出窗口后由系统压缩摘要
- 压缩过程对用户不可见，但需保证最近消息不被截断
- 跨会话只通过长期记忆建立连续性
- 新会话首次进入时，Agent 可基于记忆做简短开场，但不得暴露记忆原文

### 5.4 语音

#### 5.4.1 全局语音对话

- 全局快捷键为**按住 `Ctrl + Space`**：按住开始录音，松开转写并发送
- 快捷键在工作台任意页面生效，不要求停留在助手页
- 录音期间卡片进入“聆听”，生成与播报期间依次进入“思考”“说话”
- 转写与 Agent 回复写入**当前会话**：最近一次打开的助手会话；没有则使用“日常”
- 卡片与全局层不展示转写文字与回复文字，仅做语音播报
- 文字记录仍完整保存在会话中，用户回到助手页可回看
- 开始新的全局语音会停止当前播报；转写失败时在卡片旁显示短暂状态提示
- 输入框聚焦且输入法处于组合状态时，快捷键让位给输入法，避免误触；快捷键可在设置中自定义

#### 5.4.2 页面内语音输入

- 输入区提供麦克风按钮，采用“按住说话”交互
- 按住后显示录音状态、计时与波形，形象进入“聆听”
- 松开后调用语音转写，转写结果填入输入框，用户可编辑后再发送
- 上滑取消录音，取消后不产生转写与消息
- 录音时长上限首期建议 60 秒，接近上限时提示
- 首次使用需请求麦克风权限；拒绝后给出开启方式，不阻塞文字输入
- 转写失败时保留录音重试入口，或提示改用文字

#### 5.4.3 语音播报

- Agent 回复默认自动播报，可在输入区或设置中关闭
- 播报中消息旁显示“停止”按钮；用户发送新消息时自动停止当前播报
- 单条消息支持手动重新播报
- 语音服务不可用时静默降级为文字，并在消息旁提示“语音不可用”
- 播报与形象“说话”状态同步；播报结束回到待机
- 提供音色、语速设置入口，首期可只做开关与音色选择

#### 5.4.4 语音与文本的关系

- 语音输入是文字输入的补充，不另开会话
- 语音播报不改变消息内容与顺序
- 关闭播报不影响语音输入；关闭语音输入不影响播报

### 5.5 情绪与动作联动

#### 5.5.1 触发来源

- 模型回复中携带结构化情绪/动作标记（由回复协议约定）
- 用户手动互动
- 系统事件：首次进入、长时间未回复、错误提示

#### 5.5.2 情绪映射

| 情绪标记 | 表现 | 建议时长 |
| --- | --- | --- |
| happy | 开心、微笑 | 4 秒 |
| shy | 害羞、回避视线 | 3 秒 |
| angry | 生气、皱眉 | 4 秒 |
| sad | 难过、低头 | 4 秒 |
| surprised | 惊讶 | 3 秒 |
| neutral | 平静 | 持续到下一状态 |

#### 5.5.3 动作映射

| 动作标记 | 表现 | 说明 |
| --- | --- | --- |
| wave | 挥手 | 打招呼、告别 |
| nod | 点头 | 确认、同意 |
| dance | 跳舞 | 用户明确要求或情绪高涨 |
| think | 托腮思考 | 思考状态增强 |
| idle | 待机小动作 | 呼吸、眨眼、轻微摆动 |

- 动作标记缺失时只播放情绪，不强行播放动作
- 动作资源缺失时降级为对应情绪，不报错
- 连续相同情绪不重复触发完整动作，避免机械感

### 5.6 记忆联动

- 每轮对话结束后，系统异步判断是否写入长期记忆
- 写入成功时，在该条 Agent 消息底部显示轻量提示“已记住”，点击可跳转记忆管理
- 用户可在设置中关闭“记忆写入提示”，但不关闭记忆能力本身
- 记忆写入失败不阻塞对话，不向用户弹错误
- 记忆的查看、编辑、删除在 [04-memory.md](./04-memory.md) 中定义

### 5.7 设置

助手页设置入口只包含与本模块相关的配置：

| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
| 模型 | 主 Agent 使用的模型 | 跟随全局默认 |
| 语音播报 | 自动播报回复 | 开 |
| 语音输入 | 是否显示麦克风入口 | 开 |
| 音色 / 语速 | 播报音色与速度 | 跟随全局默认 |
| 记忆写入提示 | 是否展示“已记住” | 开 |
| 减少动态效果 | 降低动作与过渡 | 跟随系统 |
| 全局语音快捷键 | 自定义全局语音按键 | `Ctrl + Space` |
| 形象卡片显示 | 全局悬浮卡片的显示状态 | 显示 |

模型、音色等全局配置的完整管理在后续设置模块中扩展。

## 6. 交互细节

### 6.1 键盘

| 操作 | 行为 |
| --- | --- |
| Enter | 发送消息 |
| Shift + Enter | 换行 |
| Esc | 停止生成 / 取消会话重命名 |
| Ctrl + Space（按住） | 全局语音输入，任意页面生效 |

### 6.2 状态与异常

| 场景 | 表现 |
| --- | --- |
| 首次进入 | 欢迎语 + 悬浮形象卡片 + 输入框聚焦 |
| 空会话 | 展示 2–3 条推荐开场，点击填入输入框 |
| 模型不可用 | 顶部横幅提示，保留输入，提供重试 |
| 流式中断 | 已生成内容保留，显示“继续生成/重试” |
| 语音转写失败 | 输入框保留，提示重试或改文字 |
| 播报失败 | 消息保持，显示“语音不可用” |
| 形象加载失败 | 静态占位 + 重新加载 |
| 网络离线 | 禁止发送，提示检查网络；已输入内容保留 |

### 6.3 可访问性

- 所有图标按钮需有可读的 `aria-label` 与悬浮提示
- 支持键盘聚焦与 Tab 顺序
- “减少动态效果”下关闭持续动画与大动作
- 语音播报需有视觉替代（文字始终完整展示）

## 7. 数据与前端接口语义

> 后端在 UI 完成后按实际调用实现，以下为前端需要的语义，不代表最终路由。

| 能力 | 输入 | 输出 |
| --- | --- | --- |
| 获取主 Agent | 无 | 名称、形象配置、音色、模型、状态 |
| 获取会话列表 | agentId | 会话 id、标题、更新时间 |
| 创建会话 | agentId、标题 | 会话对象 |
| 获取消息 | conversationId、分页 | 消息列表 |
| 发送消息 | conversationId、文本 | 流式事件：开始、增量、情绪/动作标记、结束、错误 |
| 停止生成 | conversationId | 中止结果 |
| 重新生成 | conversationId、messageId | 新的流式事件 |
| 语音转写 | 音频 | 文本、置信度、错误 |
| 语音合成 | 文本、音色、语速 | 音频流或地址 |
| 记忆写入状态 | conversationId、messageId | 是否写入、记忆 id |

消息实体建议包含：

- `id`、`conversationId`、`role`、`content`、`createdAt`
- `status`：sending / streaming / done / failed / stopped
- `emotion`、`action`：可选，来自回复协议
- `memoryWritten`：可选，用于“已记住”提示

## 8. 验收标准

- 打开助手默认进入“日常”会话，页面只承载对话，无形象占位
- layout 顶部按钮可全局显示 / 隐藏悬浮形象卡片，隐藏状态跨页面保持并在重启后沿用
- 悬浮卡片纯透明、可拖拽、位置可记忆，且不遮挡顶部栏与左侧导航
- 按住 `Ctrl + Space` 可在任意页面发起语音对话，卡片状态依次切换且仅语音播报
- 全局语音的转写与回复完整写入当前会话，回到助手页可回看
- 显隐卡片、切换页面不丢失消息与输入草稿
- 文字消息可流式输出，可停止、重试、复制、重答、删除
- 按住说话可转写并填入输入框；取消录音不产生消息
- 回复可自动播报，可单条重播与停止；关闭播报后不再自动播放
- 回复情绪能驱动形象表情，动作能完整播放并可被新动作打断
- 点击头部/面部与快捷动作有对应反馈，且有冷却与降级
- 新建、切换、重命名、删除会话符合规则，且至少保留一个会话
- 会话面板默认展开、可整体收起，收起状态跨重启保持，切换会话后草稿恢复
- 记忆写入成功后出现“已记住”提示，关闭提示不影响写入
- 模型、语音、渲染失败时均有可恢复的提示，不出现空白页
- 明暗主题下页面、消息、输入区与悬浮卡片均正常可读
- 小屏下悬浮卡片自动缩小，不遮挡输入区与发送按钮

## 9. 开放问题

| 问题 | 影响 | 建议处理 |
| --- | --- | --- |
| 形象渲染最终选型（3D VRM / 视频渲染） | 性能、资源体积、动作上限 | 技术选型后补充渲染层验收 |
| `Ctrl + Space` 与输入法 / 浏览器快捷键冲突 | 全局语音是否可靠 | 联调时确认，提供自定义 |
| 全局语音与“当前会话”的绑定策略 | 对话归属与用户预期 | 默认最近会话，确认后固化 |
| 会话搜索与自动命名策略 | 会话变多后的查找效率 | 首期自动命名，搜索后续评估 |
| 情绪/动作标记的回复协议 | 模型输出稳定性与前端解析 | 与模型接入方案一起确定 |
| TTS / ASR 的本地或云端方案 | 延迟、成本、离线可用性 | 语音模块细化时确定 |
| 模型接入与多模型切换 | 设置项与对话质量 | 与 Agents 配置共用一套模型配置 |
| 上下文压缩阈值与策略 | 长对话稳定性 | 联调阶段确定 |
| 是否支持图片/文件消息 | 输入区与消息类型扩展 | 首期不做，后续评估 |
| 记忆写入提示的展示频率 | 打扰程度 | 首版按“每条写入提示”，可改为聚合提示 |
| 形象动作资源清单 | 渲染层工作量 | 与美术/模型资源一起确定 |
