# Bowknot Workbench

本地优先的 AI 助理与多 Agent 协作工作台，基于 [mygo](https://github.com/egoist/mygo) 构建的原生 Go 桌面应用。

所有会话、任务、记忆与产物都保存在本机，核心界面是立即模式原生 UI（无 WebView），只有安装的第三方应用在独立沙箱 WebView 中运行。

## 产品定位

Bowknot 把「一个贴身助理」和「一支可组建的员工团队」放在同一个工作台里：

- **主助手**：有虚拟形象、人设与长期记忆，负责日常对话、执行任务与调度员工
- **员工 Agents**：按需创建的不同角色 Agent，可单独对话，也可拉群协作，群聊由主 Agent 负责任务派发与汇报
- **任务**：跨 Agent 的任务状态机、并发调度、超时重试与过程审计
- **长期记忆**：每个 Agent 独立作用域，支持写入、检索注入、日/周摘要与开关管理
- **产物**：文档、代码、图片、链接等可复用内容独立落盘，与消息和任务关联
- **应用与插件**：本地/远程 tar 包安装，能力授权、工具开关与数据清理
- **模型配置**：多服务商、多模型，支持拉取模型列表、连接测试与默认模型

## 已实现功能

### 对话体验

- 多轮流式回复、停止生成、重答、复制、删除消息
- Markdown 正文渲染，用户消息与 Agent 消息分组件呈现
- **思维链**：解析 `reasoning_content`，实时展示并随消息落库，重启后可回看
- **工具调用链**：思考与工具调用按发生顺序内联展示，可折叠；刷新后仍保留完整记录
- 危险工具执行前弹窗确认，工具结果与状态（执行中/成功/失败/拒绝）可见
- 会话置顶、重命名、删除；消息分页加载
- 模型选择器；图片理解、上下文长度与最大输出在设置中维护

### 员工与群聊

- 创建和编辑 Agent 人设：名称、性别、年龄、性格、职责、对用户的称呼与补充说明
- Agent 独立会话、置顶、重命名与删除
- 多 Agent 群聊：成员依次讨论，群主汇总并派发/汇报任务
- 员工页内直接查看任务线程、产物与记忆

### 任务协作

- 任务状态机（排队、执行中、完成、失败、取消）与并发上限
- 超时、最大尝试次数与指数退避重试，参数可在设置中调整
- 任务页支持统计、筛选、搜索与过程详情（步骤、工具调用、产物）
- 主助手 / 员工 / 群聊均可发起任务，完成任务自动回到来源会话汇报

### 长期记忆

- 模型通过内置工具主动记忆、检索、更新与遗忘
- 记忆按 Agent 作用域隔离，支持按天/周摘要与关键词检索
- 回复自动注入相关记忆，前端展示「已记住」标记与记忆面板
- 记忆总开关、条数与字符预算、时间窗口可配置

### 产物

- 内置 `builtin_save_artifact` 工具，Agent 产出的内容统一托管到应用数据目录
- 支持 Markdown、文本、代码、图片、链接、HTML 源码与通用文件
- 消息卡片、任务详情、右侧 Drawer 预览与独立「产物」一级页面
- 不内嵌渲染 HTML/JS，需要时用系统应用或浏览器打开

### 应用与插件

- 包管理：manifest 校验、安全解包、原子安装/卸载、记录与文件同事务
- 支持本地目录、本地 tar、远程 tar，安装前可预览
- 应用工具开关、应用数据清理；插件可按 Agent 授权
- 应用在独立窗口内运行，使用 Untrusted 沙箱 WebView，Go 能力不可直接调用
- 内置示例应用与文件系统插件，首次启动自动安装

### 模型与设置

- 多服务商：名称、类型、BaseURL、API Key（脱敏保存），支持连接测试
- 多模型：从服务商拉取或手动添加，可设置默认模型
- 模型元信息：是否支持图片理解、上下文长度、最大输出长度
- 设置中心分类：模型服务、全局提示词、任务调度、群聊与工具、记忆、外观、数据与日志、关于
- 运行参数保存在 `settings.v1`，保存即生效；模型配置保存后重启生效
- 明暗主题切换并持久化，品牌色 `#fb5215`

### 基础设施

- SQLite 持久化：单门面 + 子 store + 事务克隆 + 版本化迁移
- OpenAI 兼容 SSE 网关：多 Provider 路由、重试、取消与错误分类
- 工具注册与执行外壳：授权校验、危险审批、审计记录
- 日志 10MB 轮转保留 5 份；数据目录、配置路径与备份说明见 [docs/operations.md](docs/operations.md)

## 技术栈

- Go 1.27+
- [mygo](https://github.com/egoist/mygo) v0.9.0 原生 UI（立即模式，无 WebView）
- SQLite（`modernc.org/sqlite`，纯 Go 驱动）
- UI 与后端分离：UI 只依赖 `internal/contract`，业务编排在 `internal/app`，持久化统一走 `internal/store`

## 目录结构

```text
cmd/desktop/main.go          启动入口：自检、装配 store/网关/安装器并注入壳层
internal/contract/           接口与 DTO，一个模块一个文件
internal/app/                用例编排：助手、员工、群聊、任务、记忆、产物、应用、插件、设置
internal/domain/             领域模型，store 与 app 共用
internal/store/              SQLite 持久化：门面 + 子 store + 迁移 + 种子
internal/infra/
├── config/                  config.json 加载校验与密钥脱敏
├── llm/                     OpenAI 兼容 SSE + 多 Provider 路由 + Fake
├── package/                 包管理：manifest、安全解包、下载、安装卸载
└── tool/                    工具注册表与执行外壳：授权、审批、审计
internal/builtin/            embed 的内置应用/插件 tar
internal/platform/           paths / lifecycle / id / logging
internal/ui/
├── shell/                   窗口外壳：自绘标题栏、一级导航、应用启动器
├── pages/                   原生页面（apps / assistant / agents / tasks / artifacts / plugins / settings / aigc）
├── components/              公共组件（Button、Card、MessageView、Timeline、Modal、Icon 等）
├── theme/                   品牌主题与明暗色 token
└── format/                  时间、相对时间、文件大小格式化
docs/                        设计与实施文档（协作链路、产物、记忆、设置、运维）
```

## 快速开始

环境要求：Go 1.27+；Windows 上运行第三方应用需要 WebView2 运行时。

```bash
go tool mygo dev      # 开发模式运行
go tool mygo build    # 构建，产物输出到 build/
```

首次启动会自动创建数据目录 `~/.bowknot-workbench/`（数据库、配置、日志、产物与安装包），并安装内置示例应用/插件。

## 质量校验

gofmt -l .            # 格式检查
